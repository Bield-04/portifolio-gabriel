# Portfólio — Gabriel Barreto da Silva

Portfólio pessoal feito apenas com HTML, CSS e JavaScript.

## Estrutura

```text
portfolio-gabriel/
├── index.html
├── style.css
└── script.js
```

## Rodando localmente

Você pode abrir `index.html` diretamente no navegador.

Ou iniciar um servidor local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Publicando no GitHub Pages

1. Crie um repositório para o portfólio.
2. Envie `index.html`, `style.css` e `script.js`.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve.
